MyTimetable Windows 课表导入助手

无需安装 Node.js，无需输入任何开发命令。

一、下载（下载过的用户直接看第二节）
1. 登录 GitHub，打开 my-timetable 仓库，点击 Actions。
2. 左边点击“构建 Windows 浏览器扩展”，选择最新的绿色勾号运行。
3. 页面底部找到 Artifacts，点击 MyTimetable-Windows-Helper 下载 ZIP。
   不要下载仓库右上角 Code → Download ZIP，那是项目源码，不是安装包。
   产物保留 30 天。过期时可在 Actions 点击 Run workflow 重新生成。

二、安装（仅首次需要）
1. 在 Windows 文件资源管理器中找到 ZIP，右键 → 全部解压。
2. 把解压后的文件夹放到固定位置，例如“文档\MyTimetable助手”。安装后不要删除或移动。
3. Chrome 地址栏输入 chrome://extensions 后按回车。
   Edge 地址栏输入 edge://extensions 后按回车。
4. 打开“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择解压出来、能看到 manifest.json 的文件夹。
   不要直接选择 ZIP，不要选择外层不含 manifest.json 的文件夹。
6. 在浏览器工具栏的拼图图标中，找到“MyTimetable 本地导入助手”，点击固定。
   首次安装会自动打开中文指南。若浏览器阻止自动打开，可在助手里点“安装与使用说明”。

三、使用（每次导入）
1. 先打开助手查看步骤，再在学校允许的 Chrome / Edge 入口正常扫码登录。
   助手不会替你登录，也不能接管企业微信客户端内的窗口。
2. 登录完成后，打开自己的课表页面，再点工具栏助手图标。
3. 点击“我已登录，开始读取课表”。关闭助手小窗口，回到学校页面。
4. 在学校页面选择完整学期，点击“查询”。不要刷新整个网页。
5. 再打开助手，点击“检查课表”。看到课程数量及课程列表后核对内容。
6. 点击“导出课程 JSON”，保存文件。没有读到课程时导出按钮不可用。
7. 完成后点击“停止并清空”。

登录或刷新可能跳转到新页面，原来的读取会失效。回到课表页重新点“开始读取”，再查询即可。

四、导入 iPhone
把导出的 MyTimetable-school-courses.json 发到自己的 iPhone，保存到“文件”。
在 iPhone 上最终使用的 MyTimetable 主屏幕窗口中：
导入课表 → 教务 JSON → 选择教务 JSON → 核对周次、节次、教师和教室 → 确认导入。
也可在电脑 MyTimetable 中先核对编辑，再导出完整备份，到 iPhone 用“从备份恢复”。

五、读不到课程怎么办
- 显示“请打开学校课表网页”：切换到学校页面，不能停在新标签页、扩展页或企业微信客户端。
- 显示“还没有读到课程”：关闭小窗口，在学校点学期查询，再打开助手检查。
- 登录或刷新后读不到：在新的课表页面重新点“开始读取”，再点击查询。
- 查询后仍是 0：可能是内嵌框架、缓存、编码或页面限制。助手不会假装成功。
  可使用学校允许的 PDF 导出，或 MyTimetable 的 JSON 响应正文方式。无需提供密码、Cookie 或 Token。
- 数字节次或周次显示“待核对”：不要猜，导入 MyTimetable 后对照学校课表补齐。
- “程序包无效”或“找不到 manifest”：确认选中的是解压后含 manifest.json 的文件夹。
- 下载不了工作流产物：先登录 GitHub，确认运行成功且产物没有过期。
- Windows 电脑被单位策略禁止加载扩展：联系管理员，不要绕过限制。

六、隐私
只导出课程名称、地点、教师、星期、节次和周次字段，不收集或保存登录凭据。
不上传数据、不主动请求学校、不自动同步。临时课程在停止、刷新或 10 分钟后清空。
课程文件仍是私人安排，不要公开分享。请选择自己的文件传输方式。
当前只用匿名数据验证，学校真实页面的封装或编码仍需实测，不承诺所有页面都能识别。
